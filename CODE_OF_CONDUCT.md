# Code of Conduct

## Our pledge

We want uvscope to be a useful, low-drama project for people who debug protocols. Contributors and
maintainers pledge to make participation harassment-free regardless of age, body size, visible or
invisible disability, ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal appearance, race, religion, or
sexual identity and orientation.

## Expected behavior

- Be precise about technical claims; say when something is unverified.
- Critique code and decisions, not people.
- Respect differing operational constraints (air-gapped labs, old browsers, unusual protocols).
- Do not publish another person's private information, credentials, certificates or traffic captures.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate intimidation, doxxing, sustained disruption,
or publishing private data without consent.

## Enforcement

Maintainers may remove comments, close issues, or ban contributors for behavior that violates this
code. Report concerns privately through the repository security contact. Reports will be reviewed
promptly and kept confidential.

This code is adapted from the Contributor Covenant, version 2.1.
